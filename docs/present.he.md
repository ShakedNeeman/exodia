# הצגה — מה להגיד

שבעה שקפים. דף: [`../ui/present.html`](../ui/present.html). אנגלית: [`present.md`](present.md).

הסיפור: בעיה מהמטלה → איך פתרתי כל דרישה → הרעיון → הפלואו → כלים → החלטות → מסכים.

| # | שקף | מה להגיד |
|---|---|---|
| 1 | הבעיה | לא עוד דיסק. להכניס קבצים גדולים ומגוונים, ואז למצוא אותם בלי `/mnt/storage3`. |
| 2 | הדרישות | כל שורה במטלה הפכה לכלל. העלאה בחלקים ל-S3. מטא-דאטה לפני בייטים. העשרה ברקע. גלישה לוגית. |
| 3 | הרעיון | פיצלתי בייטים ממשמעות. חתמתי URL, לא העברתי קובץ. |
| 4 | מקצה לקצה | כוונה → העברה → חותמת → העשרה. מחותמת הקובץ כבר ניתן להורדה. |
| 5 | כלים | React, Spring+Postgres, S3, Python, OpenSearch. כל אחד לדרישה. |
| 6 | החלטות | לא דרך השרת. מטא-דאטה קודם. unknown הוא טיפוס. לא עץ תיקיות. |
| 7 | מסכים | Ingest ואז Browse. אחר כך UML רק אם נכנסים לעומק. |
