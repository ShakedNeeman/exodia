# הצגה — מה להגיד

תשעה שקפים. דף חי: [`../ui/present.html`](../ui/present.html) (EN / עב, חצים במקלדת). אנגלית: [`present.md`](present.md).

| # | שקף | מה להגיד |
|---|---|---|
| 1 | קטלוג מול מחסן | הבעיה היא לא אחסון. כבר יש טרות. הבעיה היא להכניס קבצים מגוונים, ואז למצוא אותם. בייטים ב-S3. משמעות ב-Postgres. |
| 2 | ארבע דרישות | העלאה אמינה, מטא-דאטה בהעלאה, העשרה איפה שאפשר, גלישה לוגית. כל בחירה מגיעה משם. |
| 3 | שני מישורים | חתמתי URL. לא העברתי קובץ. בקרה = JSON. בייטים = חלקים ל-S3. S3 מדביק; הוא לא SQL ולא נגן וידאו. |
| 4 | ארבעה שלבים | כוונה → העברה → חותמת → העשרה. הקובץ שימושי מ-`uploaded`. parser שנכשל לא מחביא אותו. |
| 5 | Postgres מול Redis | מחברת מול מד מהירות. Redis = מה האחוז. Postgres = אילו חלקים חסרים. לא הפוך. |
| 6 | אותו רגע, שתי כתיבות | חלק 3812: שורה ב-`upload_part` (resume), דריסה של `progress:upl_44c` ב-Redis (הבר). |
| 7 | אם אחד נופל | Redis נמחק: הבר נעלם, ההעלאה ממשיכה. Worker נפל: הקובץ כבר uploaded. Postgres אבוד: זו הקטסטרופה. |
| 8 | כלים | S3 מחסן. Postgres מחברת. Redis מד. Spring קטלוג. Python פורמטים. OpenSearch אינדקס. |
| 9 | סיום | בייטים לא ב-API. מטא-דאטה ממדרגה ראשונה. unknown הוא טיפוס. גלישה היא קטלוג. אחר כך מסכי העלאה + גלישה. שאלות עמוקות → UML. |
