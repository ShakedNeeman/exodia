sequenceDiagram
  actor Client
  participant API as Catalog API
  participant PG as PostgreSQL
  participant Redis as Redis
  participant S3 as Amazon S3
  participant SQS as SQS
  participant W as Workers
  participant OS as OpenSearch

  Note over Client,OS: 1. Intent
  Client->>API: POST /uploads + user metadata
  API->>PG: INSERT draft rows
  API->>S3: CreateMultipartUpload
  S3-->>API: uploadId
  API->>Redis: SET progress pct=0
  API-->>Client: session + presigned URLs

  Note over Client,OS: 2. Transfer
  loop 3 parts in flight
    Client->>S3: PUT part N
    S3-->>Client: ETag
    Client->>API: part N landed
    API->>PG: INSERT upload_part
    API->>Redis: SET progress overwrite
  end

  Note over Client,OS: 3. Seal
  Client->>API: POST complete
  API->>S3: CompleteMultipartUpload
  S3-->>API: object assembled
  API->>PG: asset=uploaded
  API->>Redis: DEL progress
  API->>SQS: asset.uploaded

  Note over Client,OS: 4. Enrich
  SQS->>W: asset.uploaded
  W->>S3: range GET
  W->>PG: technical_metadata
  W->>S3: PUT derived
  W->>OS: search document
  W->>PG: asset=ready

  Note over Client,OS: Browse
  Client->>API: GET /search
  API->>OS: query
  Client->>S3: GET derived
